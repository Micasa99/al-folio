# PDF assets

Drop your CV here as `cv.pdf`:

```
assets/pdf/cv.pdf
```

The download icon will then appear next to the CV link in the navbar (configured via `cv_pdf:` in `_data/socials.yml`).

If you'd rather have al-folio auto-render a CV from `_data/cv.yml`, leave `cv_pdf:` blank in `_data/socials.yml` — the `/cv/` page will fall back to the live-rendered CV.
